# Libft

A custom C library developed as part of the 42 curriculum.

## About

Libft is the first project at 42 and serves as the foundation for many future projects in the curriculum.

The goal of this project is to recreate a collection of standard C library functions while learning:
- Memory management
- String manipulation
- Linked lists
- Pointer handling
- Low-level programming concepts
- Clean and modular code design

This library became the toolbox for later projects at 42.

---

## Features

### Libc Functions
Reimplemented standard C library functions such as:
- `ft_strlen`
- `ft_strdup`
- `ft_memcpy`
- `ft_memset`
- `ft_strncmp`
- `ft_atoi`
- `ft_calloc`
- and many more

- Bonus part with linked list management

## Compilation

Available rules:
```bash
make
make bonus
make clean
make fclean
make re
```

## Usage

Include the header in your project:
```bash
#include "libft.h"
```
